Mi participación en Medellín surgió a través de **Python Colombia** (PyCon 2018–2024).
Esos eventos fueron puntos de conexión nacional con desarrolladores de Bogotá, Medellín y otras ciudades.
No fueron contribuciones aisladas: fueron extensiones naturales del ecosistema nacional.

## JamStack Medellin: Markdown y JavaScript

Colaboración con **Kristian Moreno** para dar una charla sobre markdown en JamStack.

- **Tema:** Markdown como infraestructura de contenido en arquitecturas JAM (JavaScript + Markup)
- **Video:** [Ver charla en YouTube](https://www.youtube.com/watch?v=XZeIgYI3HTY&list=PLpJQbtSNM6grvqDhlfyW6Tnz9uOfVcYFY)
- **Conexión:** Conocí a Kristian en eventos de Python Colombia

El sitio web que estás visitando es un ejemplo vivo de esta arquitectura: Astro + Markdown + GitHub Actions.

## Node Colombia: Gatsby y Desarrollo Web

Charla de introducción a **Gatsby** para desarrollo de páginas web modernas.

- **Tema:** Gatsby, React y static site generation para aplicaciones web escalables
- **Comunidad:** [Node Colombia](https://www.youtube.com/nodecolombia)
- **Impacto:** Fue clave en mi transición a Medellín;
  conecté con personas que reforzaron mi conocimiento en JavaScript y ecosistema web

Amplió mi horizonte técnico más allá de Barranquilla, integrándome en una red nacional de desarrolladores.

**Contexto:** Estas contribuciones demuestran visión de sistema y participación activa en ecosistemas nacionales,
